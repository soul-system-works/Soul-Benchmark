# Scoring sheet — Orbit Courier (AI scorer)

How I scored: I read each game's code. I then drove each game in headless Chromium (Playwright) with real key presses: start screen, Enter, Left/Right/A/D, Up/W, P pause and resume, Enter restart, and a page reload. To check rows 3–8 and 10 directly I also used test instrumentation: I moved the ship onto packages, the station, debris and the planet, and read velocity, debris and package state. For game-2 only, the instrumentation had to be added by rewriting `game.js` as the page loaded (its state is private inside a closure). I did not edit any game file on disk. Each game ran in its own browser profile, so best scores could not cross between games. I checked every row and took screenshots. Playability is my judgement from scripted play, screenshots and the code, not from a person playing by hand.
